# Ice Cream Runner
> An endless 3D runner game built in Unity where the player navigates obstacles to collect ice creams. 

## Tech Stack & Tools
- **Game Engine:** Unity 3D
- **Scripting:** C#
- **3D Modeling:** Blender
- **VFX & Environment:** Unity Particle Systems, Custom Skyboxes

## Key Features
- **Endless Gameplay:** Procedurally generated forward movement with increasing difficulty.
- **Custom 3D Assets:** All core game objects were designed from scratch in Blender.
- **Visual Effects:** Integrated particle systems for item collection and dynamic skyboxes for immersive environments.

## How to Run Locally
1. Download and install [Unity Hub](https://unity.com/download).
2. Clone this repository: 
   `git clone https://github.com/eftihia5/Ice-Cream-Runner.git`
3. Open Unity Hub, click **Add**, and select the cloned repository folder.
4. Open the `MainScene` (or your specific scene name) in the `Assets/Scenes` folder.
5. Press the **Play** button in the Unity Editor to start running!
